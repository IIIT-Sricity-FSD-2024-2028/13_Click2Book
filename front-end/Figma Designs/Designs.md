## Design Overview

The Figma prototype contains the complete UI design for the **Click2Book Online Ticket Booking System**.

It demonstrates the workflow and user interface for different users interacting with the platform.

The system is designed to simplify the ticket booking process by connecting **customers, service providers, administrators, and support staff** within a centralized platform.

---

## User Roles

The system includes interfaces for the following user roles:

- **Customer**
- **Service Provider**
- **Admin**
- **Customer Support**

Each role has its own dashboard and features to manage their tasks within the system.
